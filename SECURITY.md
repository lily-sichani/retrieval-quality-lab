# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it through GitHub's
private vulnerability reporting feature for this repository (available under
**Security** → **Report a vulnerability** on the repository page).

Do not open a public issue with vulnerability details.

If private reporting is not available, open a minimal public issue asking for a
private contact channel. Do not include sensitive details in the public issue.

## Scope

This project is in early development. Issue 01 establishes tooling and CI only;
application code has not yet been added.
