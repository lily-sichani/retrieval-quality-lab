# Claude instructions

`AGENTS.md` is the canonical repository instruction file. Read and follow it before making changes.

- Inspect relevant files before proposing or implementing changes.
- Remain within the explicitly requested issue scope.
- Keep review effort proportional to the size and risk of the change; do not spawn unnecessary parallel agents for a tiny configuration-only diff.
- Execute commands before reporting that they pass.
- Distinguish local verification from an actual GitHub Actions result.
- Do not commit, push, or open a pull request unless explicitly requested.
